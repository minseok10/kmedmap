# 한의원 지도 샘플 웹앱

한의원의 지역, 진료분야, 전문의 여부를 필터링해서 지도와 목록으로 살펴볼 수 있는 정적 샘플 웹앱입니다.

현재 버전은 실제 서비스가 아니라 프론트엔드 학습과 화면 프로토타입을 위한 예제입니다. 샘플 예약 신청 UI는 포함되어 있지만 실제 한의원으로 전송되지 않습니다. 리뷰, 별점, 의료 상담, 로그인, 서버 DB 기능은 포함하지 않았습니다.

## 배포 주소

Cloudflare 서비스를 활용해 아래 주소에서 둘러볼 수 있도록 웹 호스팅되어 있습니다.

https://kmed.minseok.site

## 사용 기술

- HTML
- CSS
- JavaScript
- Leaflet.js
- OpenStreetMap 타일
- localStorage

React, Next.js, TypeScript, Node.js 서버, 빌드 도구는 사용하지 않습니다.

## 실행 방법

브라우저에서 `index.html` 파일을 열면 실행할 수 있습니다.

다만 Leaflet 지도 타일을 안정적으로 불러오려면 VS Code Live Server처럼 간단한 로컬 서버로 실행하는 방식을 권장합니다.

## VS Code Live Server로 실행하는 방법

1. VS Code에서 이 폴더를 엽니다.
2. 확장 프로그램에서 `Live Server`를 설치합니다.
3. `index.html` 파일을 엽니다.
4. 우클릭 후 `Open with Live Server`를 선택합니다.
5. 브라우저에서 샘플 웹앱을 확인합니다.

## 샘플 데이터 안내

기본 한의원 데이터 20개는 `app.js`의 `SAMPLE_CLINICS` 배열에 들어 있습니다.

모든 기본 데이터는 실제 의료기관 정보가 아닌 가상의 샘플 데이터입니다. 좌표는 도시 중심 근처의 그럴듯한 위치를 사용했지만, 이름과 주소는 실제 한의원처럼 오해되지 않도록 샘플 표현으로 작성했습니다.

## localStorage 저장 방식

사용자가 직접 추가한 한의원은 서버 DB가 아니라 브라우저의 `localStorage`에 저장됩니다.

저장 키는 다음과 같습니다.

```text
kmed-map-user-clinics
```

샘플 예약 신청 데이터는 별도 키에 저장됩니다.

```text
kmed-map-reservations
```

같은 브라우저에서는 새로고침해도 추가한 한의원과 예약 신청 데이터가 남아 있습니다. 다른 브라우저나 다른 기기에는 공유되지 않습니다.

## 한의원 추가 방법

1. 왼쪽 사이드바의 `한의원 추가` 버튼을 누릅니다.
2. 이름, 지역, 주소, 전화번호, 진료분야, 전문의 여부, 설명, 위도, 경도를 입력합니다.
3. `추가 저장` 버튼을 누릅니다.
4. 추가한 한의원이 지도 마커와 목록에 표시됩니다.

사용자가 추가한 데이터만 삭제할 수 있습니다. 기본 샘플 데이터는 삭제할 수 없습니다.

## 예약 신청 방법

1. 한의원 목록 카드의 `예약` 버튼을 누릅니다.
2. 날짜와 시간대를 선택합니다.
3. 예약자 이름, 연락처, 요청사항을 입력합니다.
4. 샘플 예약 저장 동의 후 `예약 신청` 버튼을 누릅니다.
5. 같은 한의원, 같은 날짜에 이미 저장된 시간대는 `마감`으로 표시됩니다.

이 예약 기능은 실제 네이버예약 연동이나 실제 진료 예약이 아닙니다. 브라우저 localStorage에 샘플 데이터로만 저장됩니다.

## 지도에서 위치 선택하는 방법

1. `한의원 추가` 모달을 엽니다.
2. `지도에서 위치 선택` 버튼을 누릅니다.
3. 지도 위에서 원하는 위치를 클릭합니다.
4. 클릭한 위치의 위도와 경도가 입력 폼에 자동으로 채워집니다.
5. 나머지 정보를 입력한 뒤 저장합니다.

위도와 경도는 직접 입력할 수도 있습니다.

## 나중에 실제 서비스로 확장할 때 고려할 점

- 실제 의료기관 데이터 출처와 최신성 관리
- OpenStreetMap, Google Maps, Naver Maps, Kakao Maps 등 지도 API 선택
- 서버 DB 연동과 검색 API 설계
- 로그인, 관리자 기능, 데이터 검수 기능
- 개인정보 처리와 보안 정책
- 의료광고 관련 법적 검토
- 실제 의료기관 정보 표시 기준과 면책 문구
